# Changelog

One section per release, newest first. A release is a tag, `v<a>.<b>.<c>`, and a page on GitHub whose
text is its section here. Its heading is `## v<a>.<b>.<c> (YYYY-MM-DD)`, the date the tag is made, and
each change in it opens with one bold sentence saying what a household will notice. Installed Macs read
the first heading of that form to learn which version is out, so a release's commit begins with its own
section; `tools/release-gate` checks both before a tag is pushed (`docs/release.md`). What `main` holds
and no release names yet is under "Unreleased", which a release's commit turns into its own heading.
