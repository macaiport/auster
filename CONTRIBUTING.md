# Contributing

Auster is at the planning stage and is mostly one person's working notes. Corrections are welcome,
especially:

- **A fact that is wrong or out of date.** Model sizes, licences, access rules and engine behaviour in
  `docs/shortlist.md` and `docs/plans/` were read on the dates they give. Say what changed and where
  you read it.
- **Measurements from other Macs.** Everything measured so far comes from one Mac, an M5 Max with
  64 GB. What a model does on 16, 32, 128 or 256 GB is unknown here. Say which Mac, which macOS, which
  engine build, which exact file, and what you saw.

## House rules

1. **Don't assert what you haven't read or measured.** A claim about what code or a third party does
   comes with where it was read. A claim about what runs comes with the Mac it ran on.
2. **A number is a measurement.** Give the command and its output, not an impression.
3. **Name the exact file.** A model is a repository, a commit, a file name and a sha256. "The 4-bit
   one" is not enough: files with the same label differ by tens of gigabytes.

## Out of scope

- Adding models that are not on the list, including modified builds whose changes cannot be traced to
  the model's publisher.
- Ways around a model's licence or its publisher's access terms.
